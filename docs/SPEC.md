# SPEC · 泛发性脓疱型银屑病（GPP）工作台规格（v0.1 草案）

状态：草案 · 0 患者访谈 · 0 临床审核 · 夜班无人值守初稿（待晨审追认）· 不得把本模板当成已确认业务

## 一、问题、用户与最小闭环

泛发性脓疱型银屑病（GPP）是发作性疾病：缓解期皮肤可能接近正常，一次发热伴全身大片脓疱就可能需要急诊就医；发作与缓解交替，患者手上往往同时存在多家医院的血象与炎症化验单、体温记录、皮损照片与不同医生给出的方案。工作台的定位是**本机病程资料工作台**：把散落的发作记录、体温与血象炎症指标、皮损评分、生物制剂与传统系统治疗用药，整理成一条可核对、可回溯的发作时间轴，并在门诊前生成能问出口的问题清单。

- 服务主体：GPP 患者本人及照护者。
- 输入：化验/检查报告与手工记录（体温、皮损照片、医嘱原话）；动作：核对入档、发作登记、用药登记、评分记录；输出：状态卡、发作时间轴与区间带、指标趋势、输注日历、门诊问题清单。
- 成功标准：两套合成档案（demo A/B）下每条功能线有真实内容；私密三出口过滤生效；全程无诊断、无用药建议、无预后判断，医学数值一律「以医嘱与报告为准」。
- 失败恢复：录入三态按钮（保存并继续录入 / 保存并关闭 / 取消）；更正=新增版本，不裸删。

## 二、方案与 ADR

- ADR-1 布局：business-first（中间主区 0.65 + 右侧 AI 面板可拖可收），与小粉宝/小橙宝一致；拒绝弹窗式 AI。
- ADR-2 第一实体选型：候选 A「随访节律型」；候选 B「发作事件型」；候选 C「治疗线型」（肿瘤语义，禁用）。选 B：GPP 病程核心是发作—缓解交替，化验、用药、评分、就诊都挂在发作与缓解节点上。
- ADR-3 评分线定位：GPPGA/PASI 作为独立评分记录线，仅登记医嘱数值与来源，不判读、不换算、不推导分期。
- 宿主能力：本机优先，apiBase 契约按 02 号；MinerU 未接入如实标注（记录导入降级为手工归档）。

## 三、信息组织维度

1. **发作维度**：发作事件（起始/持续/最高体温/伴随症状/就诊去向）是第一实体。
2. **化验维度**：白细胞、中性粒细胞、CRP、白蛋白、钙等，按报告时间连线，带参考范围与方法/机构口径。
3. **皮损维度**：GPPGA / PASI 评分——仅记录医嘱数值，不判读。
4. **用药维度**：生物制剂输注（药品名照抄处方原话）与传统系统用药（激素/阿维A/环孢素/甲氨蝶呤等）起止与剂量——仅记录，不建议。
5. **就诊维度**：就诊去向、门诊前问题清单、多医院就医信息。
6. **心理与生活维度**：担忧与生活影响，只记录不评估。

## 五、数据与 API

实体：档案(profile)、发作事件(flares)、化验(labs)、用药(medications)、评分(scores)、报告(report)、医院(hospital)、问题清单(visit_question)、收藏(saved_trial)。判读列 0：无 diagnosis/分期/疗效/风险列；派生值（缓解期第 N 天等）读时算不落库。详见 CLINICAL-DATA.md；schema M3 冻结。

## 六、设置与配置页面

三 tab（工作区/文档解析/临床数据库）：资料目录口径「拒绝主目录/桌面/下载根/tmp」；MinerU 未接入态「勾选与保存不联网」+ 免费额度上限文案；临床数据库 tab 显示快照条数/日期/通道终态（ClinicalTrials.gov v2 + ChiCtr 快照，与实际使用一致）。

## 七、UI 与原型一致性

原型 prototypes/v0.2；ui-parity 逐字符；语义 token（assets/tokens.css）；正文 15px、tabular-nums；断点 1180/900/600，390px 手机窄宽必验；页脚贴底；:focus-visible ring。PARITY.csv 在 M2 维护。

## 八、验收要点

1. 两套合成档案 A/B 切换整页联动不串档；状态卡数字与 demo 唯一源一致。
2. 发作事件录入三态保存，连续录入不清屏；更正=新版本。
3. 一图秀跨方法/机构断线，「不同方法不合并」口径同屏；化验数值仅回顾不解读。
4. 输注日历与用药记录联动；界面不出现任何选药/调药/停药建议。
5. GPPGA/PASI 只显示登记值与来源；无换算、无严重度判定。
6. 私密三出口（看板摘要预览/导出/AI 上下文）共用同一过滤函数；页内「N 条中私密 M 条」。
7. 禁词扫描：诊断结论、用药建议、预后/生存期、D+N、病期线序全部为 0。
8. 空态必须给下一步按钮；AI 输出恒为「候选/预览」。

## 九、患者视角红线

每条功能线挂场景句（0 访谈改写，标注待验证）；医生任务（诊断、选药、判读、分期）一律不做；所有医学数值以医嘱与报告为准；未核实项写「未核实」；不冒充患者引语；不写死中国流行病学数字。
