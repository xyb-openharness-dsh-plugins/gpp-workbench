# PATIENT-FLOW · 患者旅程（v0.1 草案）

0 患者访谈 · 0 临床审核 · 夜班无人值守初稿（待晨审追认）

旅程按「确诊后全病程」展开：确诊→首诊→发作急诊→缓解随访→生物制剂治疗→长期复发监测。全程无诊断/治疗建议语句，所有医学数值一律「以医嘱与报告为准」。场景句为改写描述（设计假设，非一手引语），每段标注对应场景（见 SCENARIOS.md）。

## 1. 确诊 → 建档（S1）

- 患者关心的：确诊是什么、是在哪家医院确诊的、手上有哪些化验单和报告需要归档。
- 工作台能力：档案页建立患者档案（subjects/profiles）；报告登记与原件截图墙；首次发作后把散落资料逐条归档，来源统一标「手工归档」。
- 边界：工作台不回答「这病是什么原因引起的」，疾病定义只出现在疾病概要（DP 模块）并带来源行。

## 2. 首诊 → 资料整理（S1/S3）

- 患者关心的：医生开了哪些检查、化验单上的数值和参考范围、下次复查是什么时候。
- 工作台能力：化验归档（白细胞/中性粒细胞/CRP/白蛋白/钙，含参考范围、方法、机构）；多医院就医信息卡逐条记录。
- 边界：数值仅回顾不解读，解读归医生。

## 3. 发作急诊 → 发作期记录（S2）

- 患者关心的：这次发作从什么时候开始、最高烧到多少、有哪些伴随症状、去了哪家急诊、医生怎么处理的（原话照抄）。
- 工作台能力：事件页新增发作事件（起始时间、持续、最高体温、伴随症状、就诊去向）；急诊期间的化验可挂到该发作事件下；医生行动计划原话照抄呈现，不生成提醒话术。
- 边界：不判断「是否需要急诊」；发热应对只按医生已确认的原话呈现。

## 4. 缓解随访 → 看规律（S2/S3）

- 患者关心的：现在缓解第几天、距上次发作多久、近 90 天发作几次、指标有没有回到平时的样子。
- 工作台能力：首页状态卡（缓解期第 N 天 / 距上次发作 N 天 / 近 90 天发作次数，全部为已记录事实计数）；时间线发作—缓解区间带；一图秀看白细胞/CRP 等分组趋势。
- 边界：趋势线仅回顾，不预测下次发作、不给复发风险。

## 5. 生物制剂治疗 → 输注与用药记录（S4）

- 患者关心的：输注是哪天、第几次、间隔多久；传统系统药（激素/阿维A/环孢素/甲氨蝶呤等）的起止和剂量记清楚。
- 工作台能力：治疗页输注日历 + 按次登记（药品名照抄处方原话）；传统系统用药起止与剂量折叠治疗卡；三态保存连续录入。
- 边界：不出现任何选药/调药/停药建议、剂量推荐、换药时机判断；药品与剂量一律以处方与医嘱为准。

## 6. 长期复发监测 → 门诊前准备（S5/S6）

- 患者关心的：发作间隔有没有变、要问医生哪几个问题、复查要带什么材料。
- 工作台能力：门诊前问题清单（把发作间隔变化、指标异常记录与用药反应整理成能问出口的问题）；皮损评分（GPPGA/PASI）登记卡供医生参考原值；导出走私密过滤。
- 边界：问题清单是整理工具不是问诊脚本；不替医生下任何结论。

## 回程

每个一级页导航可达；每条路径有可观察产物（记录 +1 / 文件下载 / 清单条目出现）+ 一步回首页。任何时候可从顶栏「?」或首页疾病介绍入口打开疾病概要整页（四段，带来源行与「需要问你的医生」出口）。
