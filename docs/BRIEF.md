# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：泛发性脓疱型银屑病患者与照护者；以发作期—缓解期随访—长期复发监测三段旅程为主，覆盖生物制剂与传统系统治疗的用药记录。

场景：GPP 是发作性疾病：平时可能接近正常皮肤，一次发热伴全身大片脓疱就可能需要急诊；发作、缓解交替，患者手上是不同医院的血象与 CRP 化验单、体温记录、皮损照片与不同医生开的方案。工作台把这些放回一条时间轴上：哪天发作、最高体温多少、白细胞和 CRP 什么样、用过什么药、下次复查该问什么。

核心流程：
1. 打开工作台，先看今天：距上次发作多久、最近一次化验是什么时候、有没有还没问医生的问题
2. 发作来了：把起始时间、最高体温、伴随症状、就诊去向记成一次发作事件
3. 把化验与指标归档：血象、CRP、白蛋白这些数值按时间连成线，看得到每次的参考范围
4. 把用药记录对上：生物制剂输注、激素/阿维A 等系统用药的起止与剂量（照抄处方与报告原话）
5. 门诊前生成问题清单：把发作间隔变化、指标异常与用药反应整理成能问出口的问题

完成结果：一次门诊前，患者能在同一屏里找到：上次发作是什么时候、发作间隔有没有变、最近一次 CRP 和白细胞的值与参考范围、生物制剂第几次输注、要问医生哪三个问题；全程不出现任何"你这属于什么分期/该不该换药"式的判断。
