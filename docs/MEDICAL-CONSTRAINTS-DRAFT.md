## 主题 1：疾病定义与流行病学

> **对患者工作台的影响**：患者档案需支持「罕见病」标签与病种编码（GPP 列入中国第二批罕见病目录），流行病学数字不进入产品文案；档案疾病信息字段需含确诊日期、确诊机构、是否在罕见病登记体系内。

### 要点
- GPP（Generalized Pustular Psoriasis，泛发性脓疱型银屑病）是银屑病中罕见的严重亚型：红斑基础上快速泛发的**无菌性脓疱**，常伴发热等全身症状，可危及生命（来源：中国专家共识题录、国际银屑病理事会 IPC 2024 共识定义）。
- **中国官方口径**：GPP 已列入国家卫生健康委等 6 部门 2023-09-20 公布的《第二批罕见病目录》（皮肤科罕见病）。此为本次调研的中国官方定位锚点。
- 流行病学数字（**未取得官方原件核实，一律不写入产品文案**）：
  - 中国 GPP 粗患病率约 1.403/10 万、全国估计约 2 万患者——二手综述口径，未核实原始文献；
  - 全球患病率跨度 1.76/百万～124/百万（各国口径差异大）——二手；
  - 中国银屑病总体患病率约 0.47%（2008 六省市调查）/0.5%（2017 西南四省市）——《中国银屑病诊疗指南》口径，题录级。
- 发病年龄呈双峰分布；核心免疫通路为 IL-36（IL36RN 等基因突变相关，二手综述口径）。
- 疾病编码：ICD-11 下银屑病分类存在（家庭医生 ICD-11 转载条目），GPP 精确编码值**未取得/未核实**。

### 对数据字段/功能的影响
- `patient_profile` 增加：rare_disease_flag（是/否）、rare_disease_catalog_ref（「第二批罕见病目录」枚举值）、diagnosis_date、diagnosis_hospital、genetic_test_status（IL36RN 等检测是否做过，仅记录有无，不记录判读）。
- 产品文案禁止出现患病率/患者数（均为未核实二手数字）。
- 疾病科普模块措辞限定为：罕见、严重、可反复发作、发作可危及生命、规范治疗可控制——不写任何数字。

### 来源
- 中国官方：第二批罕见病目录（2023，原件未取得，人民网二手转载 S04）；《中国银屑病诊疗指南（2023 版）》题录 S06；《脓疱型银屑病诊疗中国专家共识（2022 版）》题录 S07。
- 国际：IPC 2024 共识定义 PDF（题录/可公开访问，S12）；DermNet（二手 S14）；Rare Disease Advisor（二手 S15）。
- 分级：官方原件 0 条（罕见病目录原件与 NMPA 公告均未直接取得），二手 4+，题录 2+。

## 主题 2：诊断与分型

> **对患者工作台的影响**：档案需记录「GPP 主诊断 + 亚型/病程标签 + 是否合并斑块状银屑病/银屑病关节炎」，发作记录（flare episode）作为一等实体独立建模；工作台不做诊断鉴别工具。

### 要点
- 分型（国际通述口径，二手）：
  - **泛发型 GPP**：急性 von Zumbusch 型（最经典，突发全身脓疱伴系统症状）、亚急性环形/离心环形型、妊娠期 GPP（疱疹样脓疱病 impetigo herpetiformis）、婴幼儿/儿童型。
  - **局限型脓疱型银屑病**：掌跖脓疱病（PPP）、连续性肢端皮炎（ACH，Hallopeau）——与 GPP 属不同临床实体，工作台病种定位为 GPP，局限型只作为鉴别记录维度。
- 与银屑病关节炎（PsA）：脓疱型（尤其 PPP/ACH）与 PsA 关联较密切；GPP 患者亦可发生关节受累。新近观点（IPC、Romiti 2021 综述）倾向将脓疱型银屑病视为与寻常型银屑病不同的疾病谱（IL-36 通路为核心）。工作台需支持「是否合并 PsA」记录，但**不提供关节炎自评工具**。
- 「急性发作」定义：**本次未取得中国指南对 flare 的精确定义原文**——二手综述提到中国罕见病登记语境下的描述性定义（原发性无菌性脓疱、可伴或不伴系统症状、伴或不伴寻常型银屑病、复发至少 1 次或病程持续 >3 个月），该表述为二手转述，**未核实原件，产品中不可直接使用**；工作台发作起止判定规则 = 待临床审核占位。
- 诊断鉴别（感染性脓疱病、药物反应等）属医生职责，工作台不做。

### 对数据字段/功能的影响
- `diagnosis`：subtype 枚举（GPP-vonZumbusch / GPP-annular / GPP-pregnancy / GPP-childhood / 其他-待审核）、associated_plaque_psoriasis（bool）、associated_PsA（bool + 关节受累部位自由文本）。
- `flare_episode` 实体：onset_date、resolution_date、trigger_ref、severity_tool_refs、treatment_links。**发作起止不由系统自动判定，仅记录医生/患者手工标注。**
- 不构建任何诊断/鉴别诊断功能。

### 来源
- 中国：《脓疱型银屑病诊疗中国专家共识（2022 版）》题录 S07；《中国银屑病诊疗指南（2023 版）》题录 S06。
- 国际：IPC 2024 定义共识 S12；StatPearls S13；DermNet S14；Romiti 2021 综述（PMC，二手 S16）。
- 分级：题录 2，二手 4；中国 flare 定义原件未取得。

## 主题 3：发作期临床表现与实验室指标

> **对患者工作台的影响**：`lab_results` 指标字典必须覆盖下述检验键（白细胞/中性粒细胞/淋巴细胞、CRP、血沉、白蛋白、血钙、血钠、肾功能、肝功能、体温），所有参考区间与异常判读 = 待临床审核占位。

### 要点（均为二手综述口径，用于指标字典设计，不用于判读）
- 全身症状：发热（发作中出现比例报道跨度大）、寒战、乏力。
- 血常规：白细胞升高伴中性粒细胞升高（报道约 30–70% 发作中出现）、淋巴细胞减少常见。
- 炎症标志物：ESR 升高、CRP 升高。
- 代谢/电解质：低钙血症（急性发作常见，与低甲状旁腺功能相关的严重发作个案有报道）、低钠血症、低白蛋白血症。
- 其他：尿素/肌酐升高、肝功能异常可能。
- 注意：上述任何比例与方向性描述只用于**决定指标字典收录哪些键**，不进入异常提示逻辑。

### 对数据字段/功能的影响
- `lab_results` 指标键清单（本期必须支持录入）：
  - 血常规：WBC、中性粒细胞绝对值/百分比、淋巴细胞绝对值/百分比
  - 炎症：CRP、ESR
  - 生化：白蛋白（ALB）、血钙（Ca）、血钠（Na）、尿素（BUN）、肌酐（Cr）
  - 肝功能：ALT、AST、ALP、总胆红素
  - 体征：体温（body temperature，发作记录必填维度之一）
- `lab_results` 每条记录含：test_date、test_name、value、unit、reference_range（原报告照录）、flag（患者/医生标注，非系统判读）。
- 指标卡展示规则：只展示数值与趋势，不做异常分级告警（阈值待临床审核占位，M1 不实现告警）。

### 来源
- Rare Disease Advisor「GPP Testing」（二手 S15）；DermNet GPP 条目（二手 S14）；Rivera-Díaz 2023 综述 PMC（二手 S17）；Ly 2019 诊断筛查综述（Europe PMC 题录 S18）；Medscape workup（二手 S19）。
- 分级：二手 4，题录 1；中国指南对应的实验室检查清单原件未取得（以国际二手交叉印证字典范围）。

## 主题 5：治疗全景（发作期 + 维持期）

> **对患者工作台的影响**：`medication` 表按「药物类别 + 作用机制」建模；工作台只做用药史记录与展示，**不做剂量推荐、不做疗效比较、不做选药建议**。

### 要点（只列类别与机制；剂量/疗效/优先级 = 不写入）
- **发作期（急性 GPP）**：
  - 传统系统药物：维 A 酸类（如阿维 A）、环孢素、甲氨蝶呤（中国共识/指南口径，题录）。
  - 生物制剂：IL-36 受体抑制剂（佩索利单抗，静脉，针对发作）——中国已获批（见主题 6）。
  - 系统性糖皮质激素：国际指南（德国 S1 2026）提及可在急性发作短期谨慎使用作为桥接——**中国语境的定位未从中国指南原件核实**，工作台文案不展开。
  - 支持治疗：退热镇痛、抗感染（合并细菌感染时）、补液与电解质平衡（二手综述口径）。
- **维持期 / 预防复发**：
  - 传统系统药维持：阿维 A（指南口径「急性控制后减量维持」描述）、环孢素、甲氨蝶呤。
  - 生物制剂维持/预防：IL-36 受体抑制剂皮下制剂（预防发作适应证，见主题 6，中国获批细节未核实原件）。
  - 其他生物制剂（IL-17A、IL-23 类等）：国际上有 GPP 适应证国家（如日本）；**中国 GPP 适应证未见官方证据**（见主题 6），工作台用药类别清单含 IL-17A/IL-23 仅为记录兼容，不标注适应证。
- 光疗、外用药：作为辅助手段记录维度保留。

### 对数据字段/功能的影响
- `medication`：drug_class 枚举（retinoid / calcineurin-inhibitor-cyclosporine / methotrexate / systemic-glucocorticoid / biologic-IL36R / biologic-IL17A / biologic-IL23 / biologic-TNF / 其他）、mechanism_note（自由文本，仅记机制名称）、indication_source（说明书/超适应证/未知——由用户或医生标注，系统不自动判定）、dose 字段仅记录医生处方原文，不做校验。
- 功能红线：无用药建议、无剂量计算、无药物间比较排序。

### 来源
- 中国：脓疱型银屑病共识 2022 题录 S07；中国银屑病指南 2018/2023 题录 S05/S06；中国银屑病生物制剂及小分子药物治疗指南 2024 题录 S08。
- 国际：EADV S1 GPP 治疗指南（JDDG，题录 S24）；IPC GPP 指南页（题录 S25）；PMC 慢性 GPP 管理 2025（二手 S26）；PMC 传统系统药综述（二手 S27）。
- 分级：题录 6，二手 2。

## 主题 7：随访与监测

> **对患者工作台的影响**：随访模块做「随访计划提醒 + 随访记录存档」，随访频率默认值全部 = 待临床审核占位；监测指标展示依赖主题 3 的指标字典。

### 要点（指南口径描述，不转自测表）
- GPP 易复发，发作间期需定期随访，评估复发迹象与药物不良反应（二手综述 + 指南题录口径）。
- 药物相关监测维度（描述性，来源为二手综述/指南题录；具体频率与项目组合待临床审核）：
  - 阿维 A：肝功能、血脂等；
  - 环孢素：肾功能、血压等；
  - 甲氨蝶呤：血常规、肝功能等；
  - 生物制剂：按说明书/医生安排。
- 发作后早期复查血常规/CRP/白蛋白/血钙等（见主题 3）属发作管理常规——频率与项目待临床审核占位。
- 随访频率参考值（如「每 X 周」）：**本次未取得中国指南量化随访频率原文，全部留占位**。

### 对数据字段/功能的影响
- `followup_plan`：plan_id、next_visit_date（医生/患者手工设定）、monitoring_items（复用 lab 字典键）、medication_ref。
- 提醒功能只提醒「到期的手工设定的随访」，不生成医学建议。

### 来源

- 分级：题录 3，二手 2。

## 主题 8：诱发因素与记录维度

> **对患者工作台的影响**：`flare_episode.trigger` 做结构化多选 + 备注，字段枚举以下文要点为准；这是发作归因记录的字段设计依据，不做诱因风险提示。

### 要点（二手综述口径，交叉一致）
- 感染（链球菌、病毒等；儿童患者感染相关比例更高）；
- **糖皮质激素突然停用/减量过快**（多篇来源称最常见诱因，含外用强效激素；系统药骤停相关报道亦有）；
- 妊娠（妊娠期 GPP / 疱疹样脓疱病）；
- 药物：锂、水杨酸盐、碘化物、保泰松等；生物制剂治疗过程中出现/加重脓疱的报道（TNF-α、乌司奴单抗等，矛盾反应类）；
- 低钙血症；
- 精神压力；
- 遗传易感背景（IL36RN、CARD14 等）。

### 对数据字段/功能的影响
- `flare_episode.trigger[]` 枚举：infection / steroid-withdrawal / pregnancy / medication / hypocalcemia / stress / unknown / other + `trigger_note`（自由文本）。
- 关联字段：infection_event（部位/病原待用户录入）、medication_change_ref（近期停药/换药记录）、pregnancy_status（档案维度）。
- 产品不做「你因为 X 诱发了发作」类因果提示。

### 来源
- 人卫临床知识库条目（二手 S28）；徐州医科大学学报 GPP 38 例分析（题录 S29）；国际妇产科学杂志妊娠期 GPP 综述（题录 S30）；DermNet（二手 S14）；Romiti 2021（二手 S16）。
- 分级：二手 3，题录 2。

## 主题 9：预后与并发症

> **对患者工作台的影响**：科普与安全教育内容需要覆盖「发作可危及生命、需及时就医」的警示语；并发症清单用于 `flare_episode.complication[]` 字段枚举；不写生存率/治愈率。

### 要点（如实描述，二手综述口径）
- 未治疗/延误时发作可能危及生命；老年患者预后较差（合并症与系统并发症），儿童病程相对较轻但重症与致死个案亦有报道。
- 急性皮肤衰竭相关并发症：脓毒症/菌血症、水电解质紊乱（低血容量、低钙、低白蛋白）、红皮病转化（继发蜂窝织炎、丹毒、肺炎、心内膜炎等感染风险）、肝功能异常、低血压、充血性心力衰竭、肾/心/呼吸衰竭。
- 及时系统治疗可显著改善结局（方向性描述，二手口径）。
- **不写**任何生存率、死亡率数字、治愈率（本次二手来源亦未提供可靠分层数字，按要求留空）。

### 对数据字段/功能的影响
- `flare_episode.complication[]` 枚举：sepsis / electrolyte-disturbance / erythroderma / hepatic-dysfunction / heart-failure / renal-failure / respiratory-failure / hypotension / infection-skin / other。
- 患者端警示文案（固定话术，待临床审核）：发作期出现高热不退、大面积脓疱、意识改变等 → 提示立即就医；不自行判断严重度。

### 来源
- DermNet（二手 S14）；NORD GPP 页（二手 S31）；Rare Disease Advisor 预后/并发症页（二手 S15）；Medscape overview（二手 S19）；Romiti 2021（二手 S16）。
- 分级：二手 5。
