## 三、用户画像（改写描述 · 设计假设，非一手引语 · 待访谈验证）

1. **患者本人**：已确诊 GPP，处于发作—缓解交替的全病程中。核心任务：把发作记下来、把化验归档、把用药对上、门诊前整理问题清单。
2. **照护者/家属**：发作期陪同就诊、代为记录体温与发作情况（S6）；需要知道「哪些情况要联系医生」——只按医生已确认的行动计划原话呈现，不自行生成提醒话术。

## 四、痛点排序假设（无访谈，仅作设计排序依据，不做统计宣称）

1. 发作规律不可见（缓解第几天/距上次发作多久要心算）→ S2/S4 状态卡与时间线
2. 化验单散落多机构、白细胞/CRP/白蛋白各查各的，怕混着看 → S3 一图秀分组
3. 生物制剂输注与系统用药记录容易散、想不起来第几次 → S4 输注日历
4. 门诊前「不知道该问什么」→ S5 问题清单
5. 对反复发作的担忧无处安放 → S8 心理与家庭线

以上排序为设计假设，M1 访谈后重排。

## 五、与家族既有仓的对照结论

家族内皮肤科仓（pemphigus-workbench）为皮损/自身抗体随访形态，无「发热—脓疱发作」事件结构；心血管仓（pericarditis-workbench）有发作—缓解实体但指标语境不同；血液肿瘤仓（mds-workbench）病期/线序语义不适用本台。GPP 仓的差异化见 DIFF-MATRIX.md。
