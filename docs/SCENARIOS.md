# SCENARIOS · 场景清单（v0.1 草案）

0 患者访谈 · 0 临床审核 · 夜班无人值守初稿（待晨审追认）

**0 患者访谈声明**：本清单无一手患者引语。下列「场景句」为基于疾病知识的改写描述（设计假设，非一手引语），每条标注「改写句 · 待访谈验证」。0 临床审核声明：医学表述未经临床审核，阈值与数值一律「以医嘱与报告为准」。

## S1 首次发作后建档（核心线）

- 触发：确诊或首次发作后，手里有多家医院的化验单、报告与照片，资料散落。
- 操作：档案页新建患者档案；报告页逐条登记报告与原件截图；多医院就医信息卡逐条建立。
- 期望产出：档案建立 + 报告清单可按医院/日期检索；每条记录来源=手工归档；未知值显式 null 不猜测。
- 验收：两套合成档案 A/B 切换整页联动不串档；空态给下一步按钮。

## S2 发作期记录（核心线）

- 触发：发热伴脓疱加重，需要记一次发作。
- 操作：事件页新增发作事件——起始时间、持续、最高体温、伴随症状、就诊去向；急诊化验挂到该事件下。
- 期望产出：发作事件入库（三态保存，连续录入不清屏）；时间线区间带与事件泳道即时可见；状态卡「距上次发作 N 天」随数据更新。
- 验收：更正=新版本；无急诊必要性判断；医生行动计划只照抄原话。

## S3 化验归档（核心线）

- 触发：拿到新的血常规/CRP/白蛋白/钙化验报告。
- 操作：化验页录入或归档指标、数值、单位、参考范围、方法、机构、报告日期。
- 期望产出：化验记录入库；一图秀分组连线自动更新；指标卡显示最近值/差值/次数/来源。
- 验收：跨方法/机构断线（MT06）；数值仅回顾不解读；差值不带任何疗效或病情结论。

## S4 生物制剂输注记录（核心线）

- 触发：按医嘱完成一次生物制剂输注（药品名以处方为准）。
- 操作：治疗页输注按次登记——日期、药品名（处方原话）、输注次序、剂量（以医嘱为准）。
- 期望产出：输注记录入库；输注日历新增节点；「第几次输注」为已记录事实计数。
- 验收：日历节点与治疗记录同源；不生成下次输注时间建议；无任何选药/调药语句。

## S5 门诊前问题清单（核心线）

- 触发：复诊前几天，想把该问的问题提前整理好。
- 操作：就诊准备页把发作间隔变化、指标异常记录、用药反应逐条转成问题条目；导出走私密过滤。
- 期望产出：问题清单（可勾选、可排序）；导出文件中私密条目被过滤；页内「N 条中私密 M 条」。
- 验收：表单 ≤6 字段；显式编辑入口每页 ≤1；问题清单不包含任何判断性语句。

## S6 照护者代记

- 触发：发作期患者状态不佳，由家属代为记录。
- 操作：同一档案入口手工录入发作事件与体温；记录来源字段标「照护者代记」。
- 期望产出：记录入库并带来源标记；私密标记逐条可选；AI 上下文/导出过滤一致生效。
- 验收：代记记录与自记记录同一时间轴；无角色权限分叉引入的额外判定。

## S7 皮损评分登记（支撑线）

- 触发：门诊或复诊后拿到 GPPGA / PASI 评分数值。
- 操作：评分页登记量表名、总分、日期、来源（医嘱/报告原话）。
- 期望产出：评分卡按时间排列；来源行必填。
- 验收：无换算、无严重度判定、无分期结论；只显示登记值与来源。

## S8 心理与生活影响（支撑线）

- 触发：反复发作让患者与家人产生担忧，需要记录下来。
- 操作：心理与家庭页记录担忧、生活影响笔记、家人支持事项。
- 期望产出：笔记入库；只记录不评估。
- 验收：空态给下一步按钮；无情绪评分判定入库。
